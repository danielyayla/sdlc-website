# SDLC website

Tiny static-site helper library used to exercise the SDLC console end to end against GitHub.

- Make the same mistake twice → add a line here.
- Keep functions pure; every exported function gets a test under test/.
- Files under src/ start with a comment line (lint rule).

## Verifying your work
- Build: `npm run build` (must finish with no errors)
- Test: `npm test` (all tests pass)
- Lint: `npm run lint` (zero findings)
- Test files: `test/**/*.test.js`
- Max rounds: 5
