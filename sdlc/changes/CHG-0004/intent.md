# Intent: open_todos 2σ: untracked provocation file src/provoke-todo.js in the main checkout carries both TODOs

## Problem
At 2026-09-09T08:59:03Z the detection probe `grep -rn 'TODO' src test scripts | wc -l` (bands.yaml:51, run from the repo root by `sdlc serve --engine` every 1m) returned 2 after seven consecutive 0 samples from 08:52:01Z to 08:58:03Z. Cause: an untracked file src/provoke-todo.js exists in the main checkout (/…/scratchpad/e2e-gh, branch main at 3d197f5 "sdlc: sync origin/main") containing exactly two lines, "// TODO: provoke" twice. It is byte-for-byte the provocation recipe documented in bands.yaml:46 for the open_todos exit-run band: `printf '// TODO: provoke\n// TODO: provoke\n' > src/provoke-todo.js (untracked; delete it to clear)`. Evidence: (1) `git cat-file -e 3d197f5:src/provoke-todo.js` fails, so the file is not committed on main; (2) `git log --all -- src/provoke-todo.js` finds no commit touching it (the log aborts on an unreadable tree ea05eff, but no match precedes the abort); (3) this diagnose worktree at 7ef9ddb (branch sdlc/maintain/open_todos, merge-base with main is 7ef9ddb itself) has zero TODOs under src/, test/ and scripts/, because git worktrees do not carry the main checkout's untracked files; (4) the only tracked TODO strings in the repository are the comments in bands.yaml:44-46 and the copied evidence in sdlc/loop/triage/TRI-0001.md:9, neither of which is under src/, test/ or scripts/. No code, test or script change is involved: the last real merges before the breach were PR #22 (379f8e7, sdlc/records) and PR #21 (1871ea8, phase3/exit-run-prep) followed only by CHG-0002 deploy/rollback-rehearsal record commits (f7c80f7 through 68c40de). The breach commit 7ef9ddb adds only sdlc/loop/triage/TRI-0001.md. The value of 2 is exactly the file's two lines, and 2 = baseline 0 + 2σ, which is the tier the band comment predicts for this provocation.

## Proposed outcome
open_todos returns to 0 (within 1σ of the baseline 0) on the next detectEvery sample after src/provoke-todo.js is removed from the main checkout at /…/scratchpad/e2e-gh, and stays at 0 for at least 10 consecutive 1-minute samples. TRI-0001 is then dismissed as a deliberate exit-run provocation, or accepted into a change only if the human wants the provocation retired from bands.yaml. Measurable check: `grep -rn 'TODO' src test scripts | wc -l` prints 0 from the repo root and `git status --short src` shows nothing untracked.

## Affected users and systems
Users: the SDLC console operator running the phase-3 exit run (the person who created the provocation). Systems: the open_todos control band and its triage item TRI-0001; the `sdlc serve --engine` detection schedule (bands.yaml detectEvery 1m), which will keep reporting 2σ every minute while the file exists; the CI workflow .github/workflows/sdlc-detect.yml, which runs `sh scripts/sdlc.sh detect` on a fresh actions/checkout of the committed tree every 30 minutes and therefore does NOT see the untracked file and will continue to report 0, disagreeing with the local engine. The shipped site is not affected: src/site.js, the tests and scripts are unchanged and the file is not part of any commit, PR, preview, staging or production deploy (CHG-0002 deploys reference 1bcd38a, which predates the breach).

## Constraints
This was a 2σ read-only diagnose session: nothing was edited, deleted or committed, so src/provoke-todo.js is still present in the main checkout. Removing it is a working-tree action in the main checkout, outside this worktree, and is for a human to do. Detection stays deterministic; if a further TODO is added the band will escalate to 3σ and a propose job with routes pr, runbook:rollback and runbook:healthcheck (bands.yaml:56). Neither rollback nor healthcheck would change the metric because the file is not in any release. Three commands were not permitted in this session and are noted as unverified: `git ls-tree -r 3d197f5 src test scripts`, `gh run list --workflow sdlc-detect.yml`, and `stat` on the main-checkout file (so the exact creation time of src/provoke-todo.js is inferred from the samples, between 08:58:03Z and 08:59:03Z, not measured).
